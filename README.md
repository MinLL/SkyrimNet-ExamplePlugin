# SkyrimNet Plugin Examples

Three small, complete SkyrimNet plugins to copy from, plus the SkyrimNet SDK and modding docs.
Clone it, build it, install an example, then turn one into your own mod.

| Example | You learn | Needs |
|---|---|---|
| [01-papyrus-basics](examples/01-papyrus-basics) | YAML actions in a category, a version check, pushing events from Papyrus | Papyrus |
| [02-papyrus-context](examples/02-papyrus-context) | Mod data in prompts via `papyrus_util` and built-in decorators, a custom event type | Papyrus, PapyrusUtil |
| [03-cpp-native](examples/03-cpp-native) | C++ decorators and actions, event callbacks, memory queries, threading | C++, CommonLibSSE-NG |

New to SkyrimNet plugins? Read 01 first. Every file is commented for a first-time reader.

## Quick start

```powershell
git clone <this repo>
cd skyrimnet-plugin-examples
./scripts/fetch-tools.ps1          # Papyrus compiler and Spriggit, checksum-verified
./build.ps1                        # examples 01 and 02
./build.ps1 -Preset full           # all three (Visual Studio 2022 + vcpkg)
```

Each example lands in `dist/<Name>/` as a mod folder, with a zip beside it. Install the zip with
your mod manager, or pass `-DeployDir "D:\MO2\mods"` to copy the folders there on every build.

Prerequisites: CMake and Ninja (`winget install Kitware.CMake Ninja-build.Ninja`, or Visual Studio
2022), and the .NET SDK for Spriggit (`winget install Microsoft.DotNet.SDK.9`). The C++ example also
needs Visual Studio 2022 with the C++ workload and `VCPKG_ROOT` pointing at a vcpkg checkout.
Details: [docs/building.md](docs/building.md).

## Make your own

1. Copy the example closest to what you want into `examples/` under a new name, or run
   `/new-plugin` in Claude Code, which also does the renaming.
2. Rename the prefix (`ExB_`), the plugin, the quest and the layer id (`<author>.<slug>`).
3. Add `add_subdirectory(examples/<yours>)` to the root `CMakeLists.txt`.

Before you ship, read [docs/best-practices.md](docs/best-practices.md). It is short.
